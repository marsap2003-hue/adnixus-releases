# ADNIXUS for Android

The official Android installation and update information for ADNIXUS.

[Download the official APK](https://expo.dev/artifacts/eas/kYkyCpOXmIlBPRrhBfEVe3Id6i7PG1bUx94_uWBKtVs.apk)

Open the downloaded file with Android's Package installer. Install over the existing ADNIXUS app; do not uninstall it first, so your local workouts stay on your phone.

After installation, open **Me > Updates > Check for updates** to get the latest compatible improvements. When a future version needs a new installation, the app will offer its official download here. Android asks you to confirm installation.

Version: 1.0.0, official Android installation 1.

This repository contains only distribution information, not application source code. `android.json` is the app's public release catalogue.
